# HIGH LEVEL APPLICATION FLOW

## INGESTION STEP

1. Read the PDFs from the path: "input\AI Contract test"

2. Create a table "pdf_document_reconciliation" in SQLite with three columns: auto-increment ID, document_name, embedding (to store vectors of dimension 8192)
Path for keeping DB file: db

3. Use PyMuPDF to read the documents and store the embeddings for each document in the table "pdf_document_reconciliation"

## UI / REPORTING STEP

1. Create a SPA using ReactJS as embedded Babel script to show a report with:
    List of documents and below each item:
        - 10 best matching documents with similarity score

2. Heat map with documents on both X and Y axis. And similarity scores as cell values color-coded using scheme YlOrRd

3. Very simple Flask based Python backend to run code to interface with the DB and provide and feed data for the UI

4. Keep the UI and Backend code at path: webapp
